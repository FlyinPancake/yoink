yoink can scan directories and import music files into its database, matching them to artists and albums.

<Callout type="warn">
  Import currently works most reliably with folder structures created by yoink
  itself. External folder structures (iTunes, manual organization) may not be
  parsed correctly in all cases.

yoink's folder structure is opinionated as `{{Artist}}/{{Album}}/{{Track Number}} - {{Track Title}}.{{ext}}`. If your existing music is organized differently, yoink may not be able to match files to the correct artists and albums, resulting in unlinked tracks or albums in the library.

This may change in the future.

</Callout>
