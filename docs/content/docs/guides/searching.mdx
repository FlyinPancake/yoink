The search page queries all enabled metadata providers simultaneously, giving you unified results from Tidal, Deezer, MusicBrainz, and more.

## How Search Works

When you enter a query, yoink fans out the search to all registered metadata providers concurrently. Results are grouped into three categories:

- **Artists**: matching artist profiles from each provider
- **Albums**: matching albums with cover art and release info
- **Tracks**: individual matching tracks
